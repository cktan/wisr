## Globals

### Prefix

Names with these prefix refers to different module of the storage manager:

- sm_ -- general storage manager module
- smx_ -- transactional
- sms_ -- session
- smd_ -- storage


### extern thread_local int sm_errno

Stores the error number of the last error encountered in this thread.

### extern thread_local char sm_errmsg[200]

Stores a message describing the last error encountered in this thread.

### enum smx_level_t

SMX_READ_COMMITED
SMX_REPEATABLE_READ
SMX_SERIALIZABLE

## Database API

### bool sm_mkdb(const char* dbpath)

Create a database rooted at dbpath. Returns true on success, false otherwise.

### bool sm_rmdb(const char* dbpath)

Delete the database rooted at dbpath. This call is destructive and
cannot be undone. Returns true on success, false otherwise.

## Session API

### session_t* sms_connect(const char* dbpath)

Connect to a database to start a new session.

### bool sms_disconnect(session_t* session)

Disconnect from the database. The session is released. Uncommitted
transaction is forcibly aborted.
