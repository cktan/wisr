# Storage Manager

### Convention

- Functions return 0 on success, -1 otherwise.

### enum sm_errno_t

SM_ERR_PERMISSION
SM_ERR_DISKFULL

### extern thread_local char sm_errmsg[200]

Stores a message describing the last error encountered in this thread.

### enum sm_xctlevel_t

SM_XCT_READ_COMMITED
SM_XCT_REPEATABLE_READ
SM_XCT_SERIALIZABLE

## Database API

### int sm_mkdb(const char* dbpath)

Create a database rooted at dbpath.

### int sm_rmdb(const char* dbpath)

Delete the database rooted at dbpath. This call is destructive and
cannot be undone. Returns true on success, false otherwise.

## Session API

### session_t* sm_attach(const char* dbpath)

Connect to a database to start a new session.

### int sm_detach(session_t* session)

Disconnect from the database. The session is released. Uncommitted
transaction is forcibly aborted.

## Transaction API

### int sm_begin(session_t* session, sm_xctlevel_t level)

Begin a new transaction.

### int sm_prepare(session_t* session)

Prepare a transaction for commit.

### int sm_commit(session_t* session)

Commit a transaction.

### int sm_abort(session_t* session)

Abort a transaction.

### int sm_savepoint(session_t* session)

Create a savepoint. The session could accomodate only one savepoint.

### int sm_rollback(session_t* session)

Rollback to a savepoint. If sm_savepoint() was never called
before this, rollback to the point of sm_begin().

## Rel API

### int sm_mkrel(session_t* session, const char* relname);

Create a relation.

### int sm_rmrel(session_t* session, const char* relname);

Drop a relation.

## Update API

int sm_insert(session_t* session, const char* relname,
		const char* key, int klen,
		const char* data, int datalen);
		   
int sm_delete(session_t* session, const char* relname,
		const char* key, int klen);

int sm_update(session_t* session, const char* relname,
		const char* key, int klen,
		const char* data, int datalen);

## Read API

ok = sm_read(session, schema, table, key, &data)
scan = sm_scan(session, schema, table, skey, inclusive)
ok = sm_scan_next(scan, &key, &data)
sm_scan_end(scan)
