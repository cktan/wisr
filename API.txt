## Globals

### Convention

Functions return 0 on success, non-zero error number on failure.

### Prefix

Names with these prefix refers to different module of the storage manager:

- sm_ -- general storage manager module
- sme -- error
- smx_ -- transactional
- sms_ -- session
- smr_ -- relations

### enum sme_errno_t

SME_PERMISSION
SME_DISKFULL

### extern thread_local char sme_errmsg[200]

Stores a message describing the last error encountered in this thread.

### enum smx_level_t

SMX_READ_COMMITED
SMX_REPEATABLE_READ
SMX_SERIALIZABLE

## Database API

### int sm_mkdb(const char* dbpath)

Create a database rooted at dbpath.

### int sm_rmdb(const char* dbpath)

Delete the database rooted at dbpath. This call is destructive and
cannot be undone. Returns true on success, false otherwise.

## Session API

### session_t* sms_attach(const char* dbpath)

Connect to a database to start a new session.

### int sms_detach(session_t* session)

Disconnect from the database. The session is released. Uncommitted
transaction is forcibly aborted.

## Transaction API

### int smx_begin(session_t* session, smx_level_t level)

Begin a new transaction.

### int smx_prepare(session_t* session)

Prepare a transaction for commit.

### int smx_commit(session_t* session)

Commit a transaction.

### int smx_abort(session_t* session)

Abort a transaction.

### int smx_savepoint(session_t* session)

Create a savepoint. The session could accomodate only one savepoint.

### int smx_rollback(session_t* session)

Rollback to a savepoint. If smx_savepoint() was never called
before this, rollback to the point of smx_begin().

## Rel API

### int smr_mkrel(session_t* session, const char* relname);

Create a relation.

### int smr_rmrel(session_t* session, const char* relname);

Drop a relation.

## Update API

int smr_insert(session_t* session, const char* relname,
		const char* key, int klen,
		const char* data, int datalen);
		   
int sm_delete(session_t* session, const char* relname,
		const char* key, int klen);

int sm_update(session_t* session, const char* relname,
		const char* key, int klen,
		const char* data, int datalen);

## Read API

ok = sm_read(session, schema, table, key, &data)
scan = sm_scan(session, schema, table, skey, inclusive)
ok = sm_scan_next(scan, &key, &data)
sm_scan_end(scan)
